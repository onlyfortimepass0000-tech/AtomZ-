# Creative Resize & Export

Standalone, 100% client-side web tool to resize ad/social creative images for Instagram, Facebook, LinkedIn, YouTube, X, WhatsApp, Google Display, and custom sizes in one ZIP download.

## Local Dev
```bash
npm install
npm run dev
```

## Build & Deploy
```bash
npm run build
```
Build outputs static HTML, JS, CSS to `atomz.online/tools/creative-resize/`.

## Deploy as Static Site
Host the `tools/creative-resize/` directory on any static provider (Vercel, Netlify, Cloudflare Pages, GitHub Pages, Nginx, S3).
No backend or database required.
